Functions of the shaders:

In whatever texture editing software you are using you need to set it up to output the following:
- Base Color (RGB) Transparency or Opacity (A)
- ORME (RGBA) - Occlusion, Roughness, Metallic, and Emission strength. With the shaders that support
emission I have it set up to allow you to multiply the emission strength based on a slider with a
maximum of 5, and the emission color comes from the base color map.
- Normal (RGB) - Unity uses OpenGL normal maps so ensure you are converting your normal maps to
OpenGL.

For the texture masking texture, the masking works as follows:
- The masks should be black and white, embedded into the 4 channels of an RGBA image to make 4 total possible masks.
- Any mask that is entirely black will have no effect on the mask effect with exception to using that channel as a height
mask.
- Using a channel as a height mask prefers a height map to be used, but if you want to reuse a mask as a height map, set
the intensity to something like 0.1-0.2
- THE MASKS WILL LAYER OVER EACH OTHER! This layering effect is done in order from R->G->B->A with R being on the bottom
and A being the topmost texture.
- If you don't turn on a texture mask it will not be layered over a previous mask, meaning you will have the full
original texture mask present.
